Das aktuelle Passwort gilt für dieses Backoffice. Nach dem Ändern wirst du beim nächsten Anmelden das neue Passwort brauchen.

Veröffentlichen (GitHub)

"Speichern" merkt sich Änderungen nur in diesem Browser. Erst "Veröffentlichen" schreibt sie in data/content.json auf GitHub, wovon Cloudflare Pages die Website automatisch neu auflegt – danach sieht jeder Besucher die Änderung.

Dafür brauchst du ein GitHub-Zugangstoken mit Schreibrecht auf dieses Repository (tobiasmahrer-peakstudio/tobiasmahrer-heybelle). Erstelle eines unter github.com/settings/personal-access-tokens/new — als "Fine-grained token", beschränkt auf dieses Repo, mit Berechtigung "Contents: Read and write". Das Token wird nur in diesem Browser gespeichert, nie im Code.
